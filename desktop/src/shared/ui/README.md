# shared/ui

Дизайн-система: візуальні примітиви без знання домену.

```
Button · Input · Icon · Logo · Modal · Dialog · Tabs · Select · theme · tokens
```

## Правило

`shared/ui` не знає ні домену, ні бекендів.

Заборонено: `MediaCard`, `NodeStatusBadge`, `DownloadButton`, `ContinueWatching`.
Якщо компонент знає, що таке тайтл, завантаження або стан ноди — він належить
сутності чи фічі, які ним володіють, або каркасу застосунку в `app/layout`.

Прикордонний випадок вирішується так: `Image` з lazy-загрузкою і плейсхолдером —
це `shared/ui`; `Image`, що вміє будувати URL постера з `media_id`, — це
`entities/media`.

Може імпортувати: `@shared/lib` (і більше нічого зі `src`).

## Як пишеться компонент

`.tsx` і `.scss` — **без коментарів**, а `.scss` повторює вкладеність розмітки
(`&.modifier` для класів на тому самому елементі). Файли — `PascalCase`
(`Button.tsx`, `Button.module.scss`), крім `index.*` і глобальних, не-модульних
стилів (`theme/global.scss`). Правила й причини —
[architecture.md §5–6](../../../../docs/architecture.md).

## Іконки

Щоб додати іконку, достатньо покласти файл:

```
icon/assets/common/search.svg   →   <Icon name='common/search' />
```

Тека всередині `assets/` — це назва спрайта. Плагін `@neodx/svg`
([electron.vite.config.ts](../../../electron.vite.config.ts)) на кожному
dev-запуску й білді збирає з кожної групи `src/public/sprite/<група>.svg` і
перегенеровує `icon/sprite.gen.ts`, з якого береться union для `name`. Отже
перейменований чи видалений файл — це помилка компіляції в кожному місці
використання, а не порожній квадрат у рантаймі.

`resetColors` замінює жорстко вписані кольори на `currentColor`, тож іконка
фарбується як текст — `color` на батьківському елементі.

**Два згенеровані артефакти комітяться** — `sprite.gen.ts` і
`src/public/sprite/*.svg`. Не тому, що так гарно, а тому що `npm run check`
робить typecheck без білда: на чистому клоні без них він би падав.

**Чому `Icon` будує `href` сам.** Рантайм із `sprite.gen.ts` віддає кореневий
шлях (`/sprite/common.svg#user`) — це правильно для веб-сервера й порожньо для
зібраного застосунку: renderer вантажиться через `file://`, де провідний слеш
резолвиться в корінь диска. Заміряно на справжньому Electron: відносне
посилання малюється, кореневе — ні. Тому в компоненті `./sprite/...`.
