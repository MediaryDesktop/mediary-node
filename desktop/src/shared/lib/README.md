# shared/lib

Generic technical utilities: debounce, throttle, форматування дат, парсери,
дрібні хелпери.

Порожньо у фазі 0 — і це нормальний стан. Файл сюди потрапляє, коли він
знадобився двічі **й** не знає нічого про предметну область.

## Правило

`shared/lib` не знає, що таке медіа, тайтл, торент, бібліотека, нода чи хмара.

Утиліта з продуктовим знанням належить сутності або фічі. Утиліта, що знає про
конкретний бекенд, належить `infrastructure/`; механіка запиту як такого —
`shared/api`.

Перевірка проста: якщо в імені або в тілі функції є доменне слово — вона не тут.

Може імпортувати: нічого зі `src` (тільки npm-пакети).
