# lib

Generic technical utilities: debounce, throttle, форматування дат, парсери,
дрібні хелпери.

Порожньо у фазі 0 — і це нормальний стан. Файл сюди потрапляє, коли він
знадобився двічі **й** не знає нічого про предметну область.

## Правило

`lib` не знає, що таке медіа, тайтл, торент, бібліотека, нода чи хмара.

Утиліта з продуктовим знанням належить модулю-власнику. Утиліта, що знає про
з'єднання з бекендом, належить `core`.

Перевірка проста: якщо в імені або в тілі функції є доменне слово — вона не тут.

Може імпортувати: нічого (тільки npm-пакети).
